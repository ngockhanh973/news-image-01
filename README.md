## Run it

```sh
python3 main.py
```

The program copies `entry.png` (1024×1024 JPEG, 297 KB) to
`$MAKEFUN_OUTPUT_DIR/entry.png`, defaulting to `/output/entry.png`.
Standard library only, no network, deterministic — both runs write the
same bytes.
